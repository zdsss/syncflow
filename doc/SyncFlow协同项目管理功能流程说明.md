## 1. 工作空间（Todo）

### 1.1 整体布局

```
┌─────────────┬──────────────────────────┬──────────────────┐
│  左侧导航    │      任务列表（中）        │  任务详情（右）   │
│  任务分类    │  ┌──────────────────┐    │  （点击任务后     │
│             │  │ 未完成 │ 已完成   │    │   从右侧滑出）    │
│             │  └──────────────────┘    │                  │
│             │  任务卡片列表...          │                  │
├─────────────┴──────────────────────────┴──────────────────┤
│  顶部：综合查询栏（多条件搜索）                              │
├────────────────────────────────────────────────────────────┤
│  底部：快捷新建输入栏                                        │
└────────────────────────────────────────────────────────────┘
```

选中具体任务后，布局变为左中右三栏：任务列表收窄居中，右侧滑出任务属性面板。

### 1.2 左侧任务分类导航

| 分类 | 说明 | 数据过滤条件 |
|------|------|-------------|
| 全部任务 | 当前用户所有任务 | `assignee_id = 当前用户` |
| 今日 | 今天到期的任务 | `due_date = today` |
| 本周 | 本周到期的任务 | `due_date BETWEEN 本周一 AND 本周日` |
| 本月 | 本月到期的任务 | `due_date BETWEEN 本月1日 AND 本月末` |
| 预警 | 即将超期 | `is_warning = true` |
| 超期 | 已超期未完成 | `is_overdue = true` |
| 阶段 | 阶段类型任务 | `type = 'STAGE'` |
| 任务 | 普通任务 | `type = 'TASK'` |
| 问题 | 问题跟踪 | `type = 'ISSUE'` |
| 风险 | 风险管理 | `type = 'RISK'` |
| 建议 | 改进建议 | `type = 'SUGGESTION'` |
| 活动 | 会议/活动 | `type = 'ACTIVITY'` |
| 变更 | 变更申请 | `type = 'CHANGE'` |
| 关注 | 用户标记关注 | `tsk_task_watcher.user_id = 当前用户` |
| 里程碑 | 里程碑任务 | `type = 'MILESTONE'` |

### 1.3 综合查询栏

- **空格分隔**：多条件 AND 关系，如 `电池 设计` → 标题同时包含"电池"和"设计"
- **英文逗号分隔**：多条件 OR 关系，如 `电池,BMS` → 标题包含"电池"或"BMS"
- 查询结果实时显示在中间任务列表

### 1.4 底部快捷新建输入栏

输入任务名称后，通过特殊字符触发快捷设置弹窗：

| 触发字符 | 功能 | 说明 |
|---------|------|------|
| `@` | 选择负责人/参与人 | 默认显示本部门联系人；首字母或上下键定位；第一个选定者为负责人（显示 @ 前缀）；再次选择已有参与人则取消 |
| `￥` 或 `$` | 工时/工期输入 | 弹出工时（小时）和工期（天）输入框 |
| `%` | 任务类型选择 | 不输入时默认使用系统设置中的默认类型（默认为"任务"） |
| `^` 或 `……` | 我的任务模板 | 未设置个人模板时显示通用模板；均未设置时提示"尚未设置我的任务模板" |
| `#` | 所属项目 | 支持项目名称首字母简拼快速定位；可展开项目分类结构树 |
| `*` | 交付物模板 | 由有权限用户在系统设置中维护 |
| `&` | 工作流模板 | 在左侧导航"流程定义"页签中定义 |

**任务模板逻辑：**
```
用户输入 ^ 时
  ├─ 有个人模板（scope=PERSONAL）→ 显示个人模板列表
  ├─ 无个人模板，有通用模板（scope=GLOBAL）→ 显示通用模板列表
  └─ 均无 → 弹出"尚未设置我的任务模板"提示
```

回车后创建任务，任务模板可携带下一级子任务。

## 2. 项目管理

### 2.1 项目结构树

```
根节点
├── 文件夹（项目分类）
│   ├── 子文件夹
│   └── 项目
│       ├── 阶段（STAGE，项目直属下一级任务默认为阶段类型）
│       │   ├── 任务
│       │   │   └── 子任务（多级）
│       │   └── 里程碑
│       └── 里程碑
└── 项目
```

**悬停菜单（鼠标悬停约 0.5~1 秒弹出）：**

| 节点类型 | 可用操作 |
|---------|---------|
| 根节点 | 新建文件夹、新建项目 |
| 文件夹 | 新建文件夹、新建项目、通过模板创建项目、编辑、删除、加载工作流 |
| 项目 | 新建阶段、编辑项目、删除项目、设置参与人、设置工时、设置工期、设置项目模板、设置提醒策略、加载工作流 |
| 阶段/任务 | 新建子任务、编辑、删除、设置负责人/参与人、设置工时、设置工期、设置类型、设置提醒策略、加载工作流、**设置依赖关系** |

### 2.2 右侧属性面板

选中项目/阶段/任务后，右侧显示：

1. **顶部操作行**：对象名称、完成百分比、开始 / 暂停 / 停止 / 重新开始 / 关注 / 取消关注 / 编辑
2. **推进时序图**：从计划开始到计划结束的时间轴
   - 黄色：已完结部分
   - 蓝色：已开始未完结部分
3. **页签切换**：基本属性 / 计划表 / 泳道图 / 甘特图

### 2.3 任务依赖关系

支持四种依赖类型：

| 类型 | 含义 | 说明 |
|------|------|------|
| `SS` | Start-Start | 当前任务的**开始**取决于特定任务的**开始**（同步开始） |
| `SF` | Start-Finish | 当前任务的**开始**取决于特定任务的**结束**（顺序开始） |
| `FS` | Finish-Start | 当前任务的**结束**取决于特定任务的**开始** |
| `FF` | Finish-Finish | 当前任务的**结束**取决于特定任务的**结束** |

**设置流程：**
```
1. 悬停目标任务节点 → 点击"依赖关系"按钮
   （或在任务基本属性中点击依赖关系图标）
2. 在弹窗中选定"特定任务"
3. 在特定任务后的下拉中选择逻辑关系（SS/SF/FS/FF）
4. 确认保存
```

### 2.4 计划表（Schedule Tab）

- 以表格形式展示选定对象及其下所有层级任务的基本属性
- 在结构树区域点击编辑悬浮按钮后，表格行进入可编辑状态，焦点离开自动保存
- **按工期自动顺延开关**：开启后修改某任务的计划时间，后续所有任务按各自工期和依赖关系自动顺延
- 已开始的任务只允许修改计划结束时间
- 过滤开关：仅显示阶段任务 / 仅显示里程碑任务

### 2.5 泳道图（Swimlane Tab）

- **行**：部门（在系统设置 → 项目组织结构中定义）
- **列**：时间轴（含当前时间竖线）
- 显示哪些部门取决于该项目所有任务负责人/参与人所属部门
- 颜色含义：
  - 黄色：已完成的交付物/里程碑
  - 蓝色：已开始未完成
  - 灰色：未开始

### 2.6 甘特图（Gantt Tab）

- 展示选定对象（项目/阶段/任务）的计划与执行情况
- 可开启"依赖关系"开关，显示任务间依赖连线
- 鼠标悬停任务条：弹出属性书签，显示负责人、参与人、计划工时、已完成工时

## 3. 中控看板

### 3.1 布局

```
┌─────────────────────────────────────────────────────────┐
│  顶部：日期导航（← 前一期 | 当前日期范围 | 后一期 →）      │
│  右上：全屏切换按钮                                       │
├──────────┬──────────┬──────────┬──────────┬─────────────┤
│ 项目总览  │ 任务统计  │ 项目进度  │ 近期里程碑│  审批待办   │
│ 卡片      │ 卡片      │ 列表      │ 列表      │  列表       │
├──────────┴──────────┴──────────┴──────────┴─────────────┤
│  部门甘特图（跨部门任务分布）                              │
└─────────────────────────────────────────────────────────┘
```

### 3.2 统计指标

| 指标 | 数据来源 |
|------|---------|
| 项目总数 / 在建 / 完工 | `prj_project` |
| 任务总数 / 已完成 / 进行中 / 超期 / 预警 | `sta_dashboard_data` |
| 工时排名 | `sta_man_hour_ranking` |
| 准时率排名 | `sta_task_statistics` |
| 近期里程碑 | `prj_milestone` |
| 审批待办 | `tsk_task WHERE type='APPROVAL'` |

### 3.3 全屏模式

点击右上角全屏按钮调用 `document.requestFullscreen()`，适合大屏展示。

## 4. 系统设置

| 设置项 | 功能 |
|--------|------|
| 个人信息 | 修改姓名、手机、头像 |
| 修改密码 | 旧密码验证 + 新密码确认 |

| 项目组织结构 | 定义泳道图中的部门行 |
| 登录记录 | 查看历史登录日志 |
| API Key 管理 | 生成/撤销 API 访问密钥 |

## 5. 数据模型关系

```
prj_project (项目/文件夹)
  └── prj_phase (阶段)
        ├── prj_milestone (里程碑)
        └── tsk_task (任务，多级树，parent_id 自关联)
              ├── tsk_task_participant (参与人)
              ├── tsk_task_watcher (关注人)
              ├── tsk_task_dependency (依赖关系 SS/SF/FS/FF)
              ├── tsk_task_comment (评论)
              └── tsk_task_activity (操作日志)

tsk_task_template (任务模板)
  └── tsk_task_template_item (模板子任务)

cfg_deliverable_template (交付物模板)
wf_workflow_template (工作流模板)

sta_dashboard_data (看板统计快照)
sta_task_statistics (任务统计，按用户/项目/日期)
sta_man_hour_ranking (工时排名)

sys_user → sys_department (用户所属部门，决定泳道图行)
```

**任务状态枚举：**

| 值 | 含义 |
|----|------|
| 1 | 未开始 |
| 2 | 进行中 |
| 3 | 审批中 |
| 4 | 已完成 |
| 7 | 超期 |

## 6. API 端点速查

### 任务模块（`/api/tasks`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tasks` | 查询任务列表（支持 type/status/assigneeId/projectId/isOverdue/isWarning 过滤） |
| POST | `/api/tasks` | 创建任务 |
| PUT | `/api/tasks/{id}` | 更新任务 |
| DELETE | `/api/tasks/{id}` | 删除任务 |
| POST | `/api/tasks/quick` | 快捷创建（解析 @/￥/%/^/#/*/& 参数） |
| GET | `/api/tasks/statistics` | 任务统计（各分类数量） |
| GET | `/api/tasks/{id}/dependencies` | 获取任务依赖关系 |
| POST | `/api/tasks/{id}/dependencies` | 设置任务依赖关系 |
| GET | `/api/tasks/schedule/cascade` | 级联顺延计算 |
| GET | `/api/tasks/templates` | 任务模板列表 |

### 项目模块（`/api/projects`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/projects` | 项目树（含文件夹） |
| GET | `/api/projects/{id}` | 项目详情 |
| POST | `/api/projects` | 创建项目/文件夹 |
| PUT | `/api/projects/{id}` | 更新项目 |
| DELETE | `/api/projects/{id}` | 删除项目 |
| GET | `/api/projects/{id}/phases/tree` | 阶段树 |
| GET | `/api/projects/{id}/milestones` | 里程碑列表 |
| GET | `/api/projects/{id}/gantt` | 甘特图数据（任务+依赖） |
| GET | `/api/projects/{id}/swimlane` | 泳道图数据（按部门） |

### 看板模块（`/api/dashboard`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/dashboard` | 看板汇总数据 |
| GET | `/api/dashboard/completed-tasks` | 已完成任务列表 |
| GET | `/api/dashboard/overdue-tasks` | 超期任务列表 |
| GET | `/api/dashboard/risks` | 风险列表 |
| GET | `/api/dashboard/current-tasks` | 当前进行中任务 |
| GET | `/api/dashboard/man-hour-ranking` | 工时排名 |
| GET | `/api/dashboard/on-time-rate-ranking` | 准时率排名 |
| GET | `/api/dashboard/in-progress-activities` | 进行中活动 |

### 综合查询（`/api/query`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/query/tasks` | 全文检索任务（支持空格AND、逗号OR） |
